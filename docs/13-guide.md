## Scope and unload

Some children use nonzero application scopes. Others belong to dynamic modules whose native base is resolved at runtime. Match exact active scope where required. A shared media RootScene basename is insufficient.

Map private members back to their native original base for relative navigation. Re-resolve module scope after unload/reload instead of retaining stale identities.

## Validation and reload

Validate archive magic/version/size, member bounds and required members before exposing cached bytes. The observed archive limit is 16 MiB. A header match alone is insufficient.

Reload at a safe ownership boundary and retain backing bytes while XUI may keep locators. Do not destroy active visuals from a background worker during rendering. Original style remains recovery when validation/loading fails.

Test signed-in/signed-out and online/offline variants, repeated open/close, children/B return, dynamic unload, profile changes and unavailable services. Service unavailability can coexist with correct styling/routing.

Do not contribute proprietary style archives; publish original observations and appropriately sanitized images you have rights to share.
