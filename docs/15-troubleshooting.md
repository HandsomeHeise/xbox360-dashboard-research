# Troubleshooting

| Symptom | Check next |
|---|---|
| Settings unavailable before creation | Restore native origin; enumerate virtual _Twist source |
| No indexed channel captions | Correct outer, index, bItemData=TRUE and handled response |
| Channel selected but target absent | Wait for materialization; inspect route deadline |
| Blank full-screen page | Was any destination created, or only the routing cover? |
| Parent opens but child fails | Restore native base and exact provider scope |
| Unrelated scene replaced | Eliminate basename-only matching |
| Wrong grid cells | Compare native binary layout fields before/after conversion |
| Self-roundtrip passes, Xbox crashes | Independent allocation budget and actual creation ABI |
| Missing focus highlight | Inherited prefix before INIT, row prototype and state frames |
| Dark palette loses icons/text | Shared palette entries and scoped contrast |
| Sibling tint leaks | Begin/End pairing, verified message prefix and alpha |
| Artwork later corrupts | Backing bytes freed or title heap unloaded |
| Wrong profile launches tile | Session/profile validation at dispatch |
| Native hub flashes at sign-in | Cover readiness and boot handoff timer |
| Guide root styled, child native | Missing child mapping/exact scope/dynamic resolution |
| Duplicate outer header | Separate outer host from inner heading; runtime text clone |

Follow the first missing event: route requested, origin restored, channel source read, selection handled, target materialized, action dispatched, scene created, base restored, child entered, B returned.

Repainting SystemScene cannot fix a failure before SystemScene creation. A cover during timeout must not be misdiagnosed as an empty loaded System page.

Use bounded event instrumentation and sanitized summaries. Do not publish raw UART/log files containing account IDs, addresses, tokens or private paths.

Keep confidence narrow. Inventory establishes membership; host fixtures establish modeled contracts; console interaction establishes that specific route/build. Record uncertainty and the next observation that could distinguish timing, services and resource failures.
