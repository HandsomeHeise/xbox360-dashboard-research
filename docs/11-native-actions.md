# Native actions and the virtual Twist regression

Locate existing native controls and let them execute their own commands/conditions. Guessing an Epix URI from a caption can select the wrong flow.

Store Add-ons through A-Z map to Games; System through Turn Off map to Settings. Their IDs in the action inventory belong to the custom control table.

## Virtual channels

The retained native hub exposes _Twist as XuiTwist. Channel captions are indexed source data, not always-present caption child buttons. While Custom owns navigation, the native hub can be suspended and unmaterialized.

Close Custom, restore origin, wait for native focus/ownership, then enumerate Twist source data. Do not assume a fixed ordinal: inserted channels and online/offline state can reorder items.

## Indexed text correction

GET_SOURCE_TEXT must request the indexed item with bItemData=TRUE. FALSE asks for control-caption semantics. Send through the correct outer object using DASH message functions; require success and bHandled before trusting returned text.

Read a bounded count, discover the desired caption index using an explicit locale table, then send SET_CURSEL for that index. This selects a virtual source item; it does not press a fabricated tab child.

The static 17559 handler at 0x922109E8 handles message 2008 through 0x92210490. These addresses explain the researched behavior, not a portable API.

## Target phase

After selecting the channel, wait for its target control to materialize and press once. Keep checking owner/profile/origin, and abort on timeout. The inspected implementation uses a five-second route deadline.

Retain the return page/focus for ordinary child navigation. Explicit Original shortcuts end the session. A blank cover during timeout is not evidence that SystemScene loaded.

## Evidence

A virtual-source fixture contains no child buttons and inserts Bing to catch fixed-index assumptions. A compiled message regression covers TRUE/FALSE, nonzero index, outer object, unhandled response and invalid arguments. Latest reported total: 153 host tests passed.

A later System route was Xbox-observed after these corrections. Other actions still need individual acceptance. Run python examples/route_model.py for an original SDK-free model of restoration and discovered-index selection.

## Controller identity after leaving Home

Closing Custom Home releases its title library and clears that library owner to0xFF. That value cannot authorize input in a later settings submenu. Keep the submenu’s saved controller identity, check the current DASH active controller, and snapshot/recheck the profile for queued work. Requests must be dropped if their focused shell, controller or profile changes.
