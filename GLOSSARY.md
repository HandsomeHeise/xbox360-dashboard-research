# Glossary

| Term | Meaning here |
|---|---|
| ABI | Actual calling convention, arguments, return values and object/message layouts |
| Base path | Resource scope used to resolve relative child requests |
| COLR | Palette section in the inspected XUR8 representation |
| DATA | Serialized object/property section |
| DASH | Dashboard-side XUI runtime |
| XAM | System-side runtime; separate from DASH's XUI implementation |
| XUI | Editable XML UI representation |
| XUR8 | Compiled version-8 UI format used by the target |
| XUIZ | UI archive container; a filename can have .xzp extension |
| Provider | Native resource package namespace such as consoles or network |
| Visual prefix | Namespace inherited during visual/prototype lookup |
| Scene contract | Root/descendant classes and IDs, bindings, layout, init and actions |
| Twist | Native virtual channel selector; source items need not be child buttons |
| Materialization | Native creation of controls/data after restoring a channel/owner |
| bItemData | Message flag distinguishing indexed item data from control-caption semantics |
| bHandled | Native message result that must be checked alongside HRESULT |
| Return bookmark | Previous custom page/focus and owner/profile intent |
| System heap | Long-lived allocation ownership independent of title heaps |
| Host-tested | A contract was checked outside Xbox; not a rendering acceptance result |
| Xbox-observed | A stated interaction/image was observed on hardware |
